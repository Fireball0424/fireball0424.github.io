## Why we need smart pointers?

In traditional C++, it's dangerous to ask programmer remembering to release resources.

The concept of smart pointers uses the idea of **reference counting**.

Note that, smart pointers included `std::shared_ptr`, `std::unique_ptr`, and `std::weak_ptr`, which need to include `<memory>`.

## `std::shared_ptr`

`std::shared_ptr` records how many shared_ptr points to an object and deletes the object automatically when the reference count down to zero.

`std::make_shared` will allocate the objects in the generated parameters and return the `std::shared_ptr` pointer of this object type, which can avoid using `new` explicit.

```cpp
// Type of pointer = std::shared_ptr<int>
auto pointer = std::make_shared<int>(0);
// Note that, it's invalid to use auto pointer = new int(0);
```

We can also get the raw pointer of `std::shared_ptr` by `get()` method without increasing the reference count.

For count management, we might use `use_count()` to get the current number of reference count of the object, and use `reset()` to remove the reference count from the object.

```cpp
auto ptr = std::make_shared<int>(1);
std::cout << ptr.use_count() << endl;   // 1

int *p = ptr.get();
std::cout << ptr.use_count() << endl;   // 1

auto ptr2 = ptr;
std::cout << ptr.use_count() << endl;   // 2
std::cout << ptr2.use_count() << endl;  // 2

pointer.reset();
std::cout << ptr.use_count() << endl;   // 0
std::cout << ptr2.use_count() << endl;  // 1
```

## `std::unique_ptr`

`std::unique_ptr` prohibits other smart pointers from point to same object.

```cpp
std::unique_ptr<int> ptr = std::make_unique<int>(0);

//invalid
std::unique_ptr<int> ptr2 = ptr;
```

However, unlike `std::shared_ptr`, there is no `std::make_unique`. (According to the book, it says C++ Standards Committee ... forgot...)

```cpp
//Implementation of std::make_unique
template<typename T, typename ...Args>
std::unique_ptr<T> make_unique(Args&& ...args) {
    return std::unique_ptr<T>( new T( std::forward<Args>(args)...));
}
```

`std::unique_ptr` cannot be copied, but we can use `std::move` to transfer it.

## `std::weak_ptr`

`std::weak_ptr` is a weak reference. Unlike `std::shared_ptr`, it will not increase the reference count.

Note that, `std::weak_ptr` has no implemented `*` and `->` operations, and thus cannot operate on resources. But we can use `lock()` to get the correspond `std::shared_ptr` safely and use `expired()` to check if the object still exists or not.

```cpp

std::shared_ptr<int> sptr = make_shared<int>(2);
std::weak_ptr<int> wptr = sptr;

std::cout << sptr.use_count() << endl;      // 1

auto lock1 = wptr.lock();
cout << *lock1 << endl;                     // 2;

sptr.reset();                               // Since the reference count of the object = 0,                                          
                                            // release the resource
if(wptr.expired()){
    cout << "expired" << endl;              // expired
}
auto lock2 = wptr.lock();                   // lock2 will be empty.
```
